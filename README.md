# CRT Retreat

A React + TypeScript retro dashboard designed for a small side CRT.

## Features

- 10 ambient GIF-based themes across different genres
- Embedded lofi player
- Browser-location weather via Open-Meteo
- Clickable CNN world news letter
- Live local time
- Rotating daily message

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
